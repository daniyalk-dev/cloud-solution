# Cloud Solution

A multi-page marketing site for a fictional cloud provider, built as a personal Next.js practice project in late 2024. The copy, testimonials and client logos are sample content, not real clients.

**Live:** https://cloud-solution-dkcent4s-projects.vercel.app

## What's in it

An animated banner with a globe, a services section that reveals sub-services as you scroll (a custom IntersectionObserver hook), a projects section, a testimonials slider and client logos (Swiper), a team section, About and Contact pages, and a header that hides on scroll down. The contact form is validated on the client and again in a Next.js Server Action.

## Stack

Next.js 15 (App Router), React, TypeScript, Tailwind CSS, Swiper, clsx

## Run it locally

npm install, then npm run dev
